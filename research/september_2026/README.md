# September 2026 WarBias source snapshots

Frozen authoring and verification scripts accompanying the [WarBias September supplement](https://huggingface.co/datasets/FairForget/WarBias/tree/main/research/september-2026).

The `outputs/` tree preserves the original authoring scripts and their workspace-relative paths. Their historical input paths are recorded in the Hugging Face preparation source inventory; these snapshots require those original inputs. For evaluation of the published prepared bundles, use the current `lm_eval.fair_uk` package and the [Fair-UK guide](../../docs/fair-uk.md). Data, annotations, model responses and experiment reports are hosted on Hugging Face.
